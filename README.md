
# text-slot-machine

A quick command-line slot machine game written in Python.

Coming from a C/C++ background, I built this as a weekend project to pick up Python syntax, get comfortable with lists and dictionaries, and see how dynamic typing feels in practice.

### How it works
- Set a deposit and bet across 1–3 lines.
- Random 3x3 reel spin with weighted symbols.
- Calculates wins/losses and updates balance until you quit.

### Run it
```bash
python main.py
